## 📌 عن المشروع

مشروع **CybeNode FakeMail API** يقدم محركاً هجيناً وسريعاً للتعامل مع البريد الإلكتروني المؤقت وتجاوز حظر استدعاءات الخوادم عبر **Cloudflare Workers**. يتيح لك هذا المستودع الربط المباشر مع واجهات البرمجة (REST API)، بالإضافة إلى أداة سطر أوامر (**Terminal CLI**) ومكتبة **JavaScript SDK** جاهزة للاستخدام في تطبيقاتك وقوالب بلوجر.

## ✨ المميزات الرئيسية

* 🚀 **أداء فائق:** معالجة الاستدعاءات وسرعة جلب الرسائل من خلال شبكة Cloudflare العالمية.
* 🛡️ **دعم كامل لـ CORS:** إمكانية الاستدعاء المباشر من قوالب بلوجر وتطبيقات React / Vue / Flutter.
* 🔐 **توثيق أمن (JWT Token):** حماية التفاعل مع صندوق الرسائل بواسطة Bearer Tokens.
* 💻 **Terminal CLI:** أداة سطر أوامر مع واجهة رسومية أنيقة لإنشاء الإيميلات ومراقبة الوارد حياً.
* 📱 **متوافق مع أدسنس:** مصمم ليعمل بسلاسة داخل قوالب البريد المؤقت المعتمدة.
